# Why there are both 57 and 58 cases in this repository

The six-jurisdiction primary chain is the same. The historical root dataset includes 58 institutions (21E/13P/24U), while the revised ICAMAC Paper 90 manuscript reports 57 (20E/12P/25U). This is a **sampling-boundary correction**, not a fuzzy reweighting:

| Changed case | Earlier 58 | Revised 57 |
| --- | --- | --- |
| Emirates Institute for Banking and Financial Studies (EIBFS, 1983) | not included | U included |
| American University of Sharjah (1997) | E included | excluded |
| University of Dubai (1997) | P included | excluded |

The 1983 older eligible EIBFS candidate shifts the fourth-position oldest-four threshold earlier, removing the two 1997 ties. Total N changes by -1; E/P/U changes (-1,-1,+1). This crosswalk uses the documented eligibility audit, not new policy re-coding. Both versions remain for transparency; the 58-case arithmetic should never be presented as if it reproduced this 57-case paper.
