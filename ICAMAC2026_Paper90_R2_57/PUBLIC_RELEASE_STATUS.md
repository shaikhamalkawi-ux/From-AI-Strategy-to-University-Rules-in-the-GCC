# Publication, data reuse, and validation boundary

The repository is public and author-identifiable. The R2 linked PDF is an **author/repository copy**; the R1 blind paper is kept unchanged. Whether the venue allows an author-identifying link during peer review must be confirmed by the authors/organizers.

The archive includes author-generated code and tables; no official government or university PDF is republished. A formal author-approved reuse license has not been selected, so repository availability is not a blanket license.

The saved numerical states have been verified arithmetically. Independent expert-coded validation of 36-source classifications and linked Arabic-English instruments has not been performed. A dated official-source register with rationale is available; full direct quote/page evidence and archival hashes remain incomplete for some records. An institutional homepage for U is a search locator, not evidence of a qualifying policy.

All claims pertain to a finite, selected corpus with 23 July 2026 cutoff. In particular: no prevalence rates, causal policy-translation evidence, population inferential confidence, implementation conclusions, or country quality rankings.
