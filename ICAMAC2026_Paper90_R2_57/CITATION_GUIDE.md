# How to cite this work

The authors' intended primary cite is the eventually published ICAMAC2026 paper **From AI Strategy to University Rules in the GCC**. No journal/proceedings DOI is known for this draft; do not invent one.

If referring to repository data prior to formal publication, explicitly report the title, version `ICAMAC2026 Paper90 R2 57-case`, access date, and a permalink to the repository commit. Cite the authorship as confirmed by the authors, not inferred from a GitHub account. Dataset and software licensing have not been finalized.

Distinguish the N=57 (20E/12P/25U) dataset from the older N=58 (21E/13P/24U) folder; they do not reproduce the same paper table.
